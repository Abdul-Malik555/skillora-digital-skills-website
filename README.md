# Skillora — Digital Skills Website

Official Skillora website for digital skills, AI, marketing, design, e-commerce and web development.

## Brand
- Electric Blue: #0088FF
- Deep Navy: #030C1E
- White: #FFFFFF
- Tagline: LEARN | GROW | SUCCEED

## Features
- Responsive modern landing page
- 12-course catalogue generated with JavaScript
- Course enquiry form
- WhatsApp submission flow
- Services and team sections
- Instagram and Facebook links
- Mobile navigation and scroll animations

## Run
Open index.html in a browser or use VS Code Live Server.

## Images
Add the provided Skillora logo, favicon, actual team photos, and course/hero images using the filenames referenced by the HTML and JavaScript files.
